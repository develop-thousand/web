# THOUSAND — A pie house from Seoul

따우전드의 실제 파이 사진을 중심으로 만든 Next.js App Router 쇼핑몰입니다. PIE, UNBOXED 콘셉트로 대형 파이 사진, 펼쳐 보는 컬렉션, 레드·코발트·버터 옐로의 인쇄물 구성을 적용했습니다. 실제 목재 매장 사진으로 미국 파이 하우스의 온기를 담았습니다.

## 실행

Node.js 22 LTS 이상을 권장합니다. Next.js 최소 지원 버전은 Node.js 20.9입니다.

```sh
npm ci
npm run dev
```

http://localhost:3100 에서 확인합니다.

```sh
npm run build
npm run start
npm run typecheck
npm run test:e2e
```

브라우저가 없는 환경에서 테스트하려면 `npx playwright install chromium`을 먼저 실행합니다. 테스트는 데스크톱과 모바일 크기의 Chromium에서 진행합니다. `artifacts/`에 화면 캡처가 저장됩니다.

## 화면과 기능

- `/`: 집중/펼쳐 보기, 디테일 확대, 방향키·스와이프 탐색, 선택 상품 담기, 상품 목록, 매장과 협업 이야기
- `/shop`: 카테고리 필터, 가격 정렬, 빠른 장바구니 담기
- `/pies/[slug]`: 8개 상품 상세, 수량 선택, 관련 상품, 판매 단위 및 식품 안내
- 전역 검색: 한글/영문 이름과 재료 검색, 검색 결과 없음 처리
- 전역 장바구니: 로컬 저장, 수량 변경/삭제, 잘못된 저장 데이터 복구, 접근 가능한 네이티브 dialog
- `/checkout`: 매장/날짜/시간을 선택하는 데모 픽업 주문; 실제 결제/예약 없음
- `/stores`: 군자/신사/성수 선택, 매장 사진/지도 전환, 공식 지도 길찾기, 종료된 하와이 팝업
- `/story`: 브랜드 이야기와 하와이 팝업 아카이브
- 모바일 반응형, 키보드 포커스, reduced-motion 지원, 없는 상품 404

## 콘텐츠 변경

상품, 가격, 판매 상태, 매장 정보는 `src/lib/catalog.ts`에서 관리합니다. 이미지는 `public/images/`에 보관하며 Next Image에서 반응형 크기 및 WebP/AVIF 최적화를 처리합니다. 출처는 `docs/asset-sources.md`에 기록했습니다.

글꼴은 Google Fonts의 Archivo Black, DM Sans, Playfair Display를 사용하며 네트워크 실패 시 시스템 서체로 대체됩니다. `src/app/unboxed.css`가 브랜드 색상과 편집 레이아웃을 적용합니다. `src/components/pie-studio.tsx`는 갤러리 상태와 키보드·포인터 인터랙션을 관리합니다. 지도는 지도 보기 선택 시 Google Maps iframe을 로드합니다.

## 실제 판매 연결 전 필요한 작업

이 프로젝트는 완성된 프런트엔드 시연입니다. 서버 주문 DB, 인증, 결제, 운영자 화면, 재고 연동은 포함하지 않습니다. 고객 이름/연락처/결제정보를 수집하지 않으며 상품 ID와 수량만 현재 브라우저 localStorage에 저장합니다. `데모 주문 완료하기`는 외부로 주문을 전송하지 않습니다.

출시 전 운영팀의 상품별 확정 가격·중량·원재료·알레르기·보관기한·픽업 가능시간·재고를 연결해야 합니다. 계절 제품의 판매 상태는 데모 설정입니다. 배송 주문은 연결하지 않았습니다. 사진에 홀 파이나 아이스크림 연출이 있어도 현재 샘플 판매 단위는 조각 1개입니다.

실서비스에서는 서버에서 가격/재고/예약 가능 시간을 재검증하고 결제 웹훅의 서명 검증과 중복 처리 방지, 주문 취소/환불 및 운영자 권한 관리 등을 구현해야 합니다. 클라이언트의 합계/재고를 신뢰해서는 안 됩니다.

샘플 페이지가 실제 주문 사이트로 검색되지 않도록 noindex가 설정되어 있습니다. 운영 정보와 이미지 사용 권한을 확인한 뒤 실제 판매 연결과 함께 조정하세요. 하와이는 2026.09.23–10.04 종료된 팝업이며 상설점으로 표시하지 않습니다.
